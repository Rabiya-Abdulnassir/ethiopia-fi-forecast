### Usage

- Digital payment trends

- Payment channels

### Infrastructure

Analyzed relationships between:

- Mobile penetration
- 4G coverage
- ATM availability
- Financial inclusion outcomes

### Key Insights

- Mobile money expansion increased access opportunities.
- Registered accounts do not always represent active usage.
- Infrastructure growth supports financial inclusion.
- Gender gaps remain a challenge.
- Limited historical survey data creates forecasting uncertainty.
